# 工作区资源管理器

替换 DSH Web GUI 原生「工作区文件」页面的快速浏览器。

## 功能

- 懒加载目录树，带文件类型图标和虚拟滚动。
- 快速打开（`Ctrl/Cmd+P`），基于一次有界的 `rg --files` 清单进行本地模糊匹配。
- 内容搜索（`Ctrl/Cmd+Shift+F`），由 ripgrep 在 Host 端执行。
- 选中文件预览中的代码后按 `Ctrl/Cmd+U` 插入 `path:start~end`；没有选中内容时优先插入打开/选中的文件路径（`@path`）。
- 把文件行拖到输入框可插入相对路径。
- Python 项目徽标：自动识别 `uv` 与 `pyenv` 项目。

## 性能

目录树按层读取，只渲染可见行；3000 文件目录约 100ms 展开、DOM 中约 40 行。快速打开只建立一次清单，后续按键在本地匹配；内置 Rust→WASM 模糊匹配器（1,472 字节）对 50,000 条路径的中位耗时约 12.7ms。内容搜索由打包的 ripgrep 执行，不把文件内容流进浏览器。

## 说明

文件预览复用宿主的文档预览来提供语法高亮和行号导航。`uv` 与 `pyenv` 项目使用同一套 Python 高亮。双击文件可打开，选中后按 Enter 也可以。

## 限制

只读，不提供重命名、删除或编辑。代码位置和语法高亮依赖原生文档预览的 DOM 结构与 `data-textpreview-url`；DSH 预览重构后可能需要适配。Host 方法使用 Typert source-mode 标记，当前在 DSH `0.2.2-rc.3` 验证。

## 语言

界面跟随 DSH 的语言设置，提供中文和英文词典；插件内没有独立语言开关。
